# 产品设计演进与能力提升

七牛商机助手围绕销售现场的实际操作，逐步完善信息采集、AI 整理、业务入库与协同执行链路。设计演进重点是减少前置操作、保持信息上下文独立，并让生成结果进入可执行的业务流程。

## 核心设计演进

| 设计主题 | 形成的产品能力 | 解决的问题 |
| --- | --- | --- |
| 现场快速采集 | 全局快捷录音，先记录材料、后关联商机 | 减少现场切换页面和提前填表的操作负担 |
| 沟通上下文隔离 | 已有录音时，新快捷录音自动进入新草稿 | 避免不同沟通材料混用 |
| 多材料处理 | 录音与补充文本共同参与生成 | 结合原始沟通及补充信息形成小记 |
| 解析结果复用 | 保留未改变材料的解析结果 | 避免小范围材料修改触发全部重复解析 |
| 下游内容更新 | 材料变化后重新生成相关小记与待办 | 排除已删除或已改变材料对结果的旧影响 |
| AI 行动提取 | 一键提取待办，并支持人工补充与编辑 | 将沟通结论整理为后续行动 |
| 跨人员协作 | 创建人与经办人分离，支持人员分派与调整 | 将跟进事项交由相关人员执行 |
| 用户任务视图 | 展示本人创建或经办的任务 | 兼顾发起事项跟踪与本人工作处理 |
| 人工核查与提交 | 原文核查、内容编辑及写入预览 | 在业务入库前完成材料和生成结果确认 |
| 商机业务联动 | 商机内聚合小记、材料与关联待办 | 使沟通历史与执行任务保持业务关联 |

## 个人设计贡献

自主提出并落地协同任务模式，将单人行动管理扩展为创建者与经办人协作；自主提出材料级解析复用与下游结果更新机制，使流程回退、材料变更及再次生成能够衔接，兼顾操作体验与内容一致性。

结合全局快捷录音、草稿隔离与人工核查，将产品流程设计落实到客户端、服务端及 AI 处理链路，形成从需求分析、架构设计、数据建模到真机验证与交付的完整工程实践。
